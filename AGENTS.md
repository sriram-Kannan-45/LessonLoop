# Repository workflow

- After each completed user-requested update, commit the project changes and push the working branch to `origin`, including one-line changes. The current project branch is `main`.
- Run checks appropriate to the change before pushing. Report a failed push or check clearly; do not claim synchronization until it succeeds.
- Keep API keys, real environment files, dependency folders, caches, and generated artifacts out of Git. Preserve existing user work and never force-push without explicit authorization.
